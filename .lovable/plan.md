# Redesign the Services page

## Goal
Create a calm, structured Services page that matches the homepage and helps SME decision-makers quickly choose the right kind of support.

## Changes
- Replace the current plain page introduction with a compact image-backed Services header using the existing operational-sector photography, a deep forest overlay, and left-aligned light text.
- Replace the five-item accordion with three detailed service sections:
  1. Get clear on what matters
  2. Respond with confidence
  3. Turn plans into progress
- Give every service the same easy-to-scan structure: introduction, included work, typical outcomes, audience fit, and a contact link.
- Replace the circular five-step process with a concise three-step "How we work" section.
- Add a Services-specific closing section with the supplied call-booking and email copy.
- Add matching Flemish Dutch content so the existing language switch remains complete.
- Use the homepage's shared title, intro, spacing, card, colour, and button patterns throughout.

## Responsive and accessibility checks
- Keep every heading, paragraph, list, and action left-aligned on desktop and mobile.
- Stack service details and process steps cleanly on narrow screens.
- Preserve semantic headings, list markup, visible focus states, image treatment, and readable contrast.
- Verify both English and Dutch at desktop and mobile sizes, including links and browser errors.

## Technical details
- Build focused Services-page presentation components rather than altering the homepage sections.
- Reuse the existing operational image asset and semantic design tokens; do not introduce a disconnected palette.
- Keep all calls to action linked to the existing contact page and email address.
